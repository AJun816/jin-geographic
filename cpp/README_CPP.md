# WMM2025 磁偏角计算程序 - C++版本使用手册

## 程序简介

本程序是一个基于 World Magnetic Model 2025 (WMM2025) 的磁偏角计算工具，使用C++实现，可用于计算地球上任意位置和时间的磁偏角（地磁偏角/磁差）。程序提供了两种使用方式：预定义测试用例和互动式计算。

## 功能特点

1. **度分秒 (DMS) 格式支持**：支持以度分秒格式输入经纬度坐标
2. **高精度计算**：使用WMM2025模型进行高精度磁偏角计算
3. **多种计算方法**：内置5种磁偏角计算方法，自动选择最适合的结果
4. **预定义测试用例**：包含7个预定义测试位置，可快速验证计算准确性
5. **互动式测试**：提供友好的命令行交互界面，支持用户自定义位置和时间计算
6. **详细输出**：可显示磁场分量、水平强度等详细信息

## 系统要求

- C++11 或更高版本的编译器
- GeographicLib 库（已包含 WMM2025 数据）
- 标准C++库

## 编译说明

使用以下命令编译程序：


```bash
g++ -std=c++11 -o dms_to_magnetic_improved dms_to_magnetic_improved.cpp -lGeographic
```

## 使用方法

### 运行程序

编译完成后，使用以下命令运行程序：

```bash
./dms_to_magnetic_improved
```

程序启动后会显示主菜单：

```
===== WMM2025磁偏角计算程序 =====
WMM2025模型初始化成功

请选择操作：
1. 运行预定义测试用例
2. 进行互动式磁偏角计算
0. 退出程序
请输入选择 (0-2): 
```

### 选项1：运行预定义测试用例

选择选项1后，程序会依次计算7个预定义测试位置的磁偏角，并显示计算结果与预期值的比较。每个测试用例的输出包含：
- 位置信息（度分秒格式和十进制度格式）
- 高度和日期
- 磁场分量（北向、东向、向下）
- 水平强度
- 计算得到的磁偏角
- 与预期值的比较结果

### 选项2：进行互动式磁偏角计算

选择选项2后，程序会引导用户输入以下信息：

1. **纬度**：度、分、秒和方向（N/S）
2. **经度**：度、分、秒和方向（E/W）
3. **高度**：以米为单位
4. **日期**：年、月、日

输入完成后，程序会计算并显示该位置和时间的磁偏角，以及相关的磁场信息。

## 输入格式说明

### 纬度和经度

程序支持以度分秒（DMS）格式输入经纬度：
- 度、分、秒均为数字
- 方向：纬度使用N（北）或S（南），经度使用E（东）或W（西）

例如：北京的坐标可以输入为39度54分0秒N，116度24分0秒E

### 高度

高度以米为单位，输入数字即可。

### 日期

日期以年、月、日的形式输入，均为数字。

## 输出说明

程序的输出包含以下信息：

- **磁场分量**：北向分量(Bx)、东向分量(By)、向下分量(Bz)，单位为nT（纳特斯拉）
- **水平强度**：H，单位为nT
- **磁偏角**：以度为单位，负值表示西向，正值表示东向

## 错误处理

程序包含完善的错误处理机制，在遇到以下情况时会显示错误信息：

- WMM2025模型初始化失败
- 输入参数无效
- 计算过程中发生异常

## 注意事项

1. 程序使用的WMM2025模型最适用于2020-2025年期间的计算
2. 对于高海拔地区，计算结果的精度可能会略有下降
3. 程序默认使用系统中安装的GeographicLib库的WMM2025数据
4. 为了获得最准确的结果，请确保输入的坐标和日期信息准确无误

## 扩展与定制

如需添加新的测试位置或修改现有功能，可以修改源代码中的以下部分：

- 在`runTests`函数中添加或修改测试用例
- 调整`calculateMagneticDeclination`函数中的计算逻辑
- 修改主菜单和交互流程

## 维护与更新

- 当有新的地磁模型发布时（如WMM2030），需要更新GeographicLib库并修改程序中的模型名称
- 定期验证计算结果的准确性，特别是在程序运行环境发生变化时
